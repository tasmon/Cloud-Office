Help

Quick reference for Cloud Word, Cloud Sheet and Cloud PowerPoint.

General Cloud Word Cloud Sheet Cloud PowerPoint

General

  • Everything is saved automatically to this browser as you work. There is no server and no account.
  • Each app keeps a list of your files in a sidebar. Use New to start another one without losing the current file.
  • Clearing your browser's site data for this page will delete everything saved here. There is no cloud backup.
  • Settings (the gear icon) has a Light/Dark/System theme switch that applies to all three apps.

Cloud Word

  • File menu: new document, open a .docx/.txt/.html file, download, print, delete, close.
  • Insert images, tables, links, horizontal lines and page breaks from the Insert menu or toolbar.
  • Click inside a table cell to enable the row/column tools in the Table menu.
  • Line spacing and paragraph styles apply to the paragraph your cursor is in, or to a selection.

Cloud Sheet

  • Click and drag across cells to select a range. Shift-click extends a selection.
  • Formulas start with =. Supported functions include SUM, AVERAGE, MIN, MAX, COUNT, COUNTIF, SUMIF, VLOOKUP, IF, IFERROR, TEXT, ROUND and more.
  • Drag the small handle at the bottom right of a column header to resize it.
  • Merge cells and freeze the header row/column from the Format menu.
  • Select a range and use Insert > Chart to add a bar, line or pie chart built from that data.

Cloud PowerPoint

  • Click an element to select it, drag to move it, and use the handle at its corner to resize.
  • Shift-click to select several elements at once, then use the Align tools to line them up.
  • Bring to front / send to back changes which element sits on top when shapes overlap.
  • Speaker notes are attached to the current slide and are included when you download a .pptx.
  • Present starts a full-screen slideshow. Use the arrow keys or click to move between slides.
