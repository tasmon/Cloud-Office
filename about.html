About Cloud Office

Version 2.0.1

What this is

Cloud Office is three document editors that run entirely in your browser: Cloud Word, Cloud Sheet and Cloud PowerPoint.

WCloud Word, a document editor that reads and writes .docx
SCloud Sheet, a spreadsheet with formulas that reads and writes .xlsx
PCloud PowerPoint, a slide editor that exports .pptx

How it works

There is no server. Files are kept in this browser's local storage (IndexedDB) and never leave your device unless you choose to download or print them. Each app is a set of static HTML, CSS and JavaScript files, meant to be opened directly or hosted on any static file host.

Third-party code included

All libraries below are bundled as local files in this download. Nothing is fetched from the internet at run time.

  • Mammoth.js, for reading .docx files
  • html-docx-js, for writing .docx files
  • SheetJS (xlsx), for reading and writing .xlsx/.csv files
  • PptxGenJS, for writing .pptx files
